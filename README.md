## ✨ Overview

**Interhact** is a platform born out of our **Final PI (Projet Intégré) Project** at **ESPRIT**, combining **Cloud Computing**, **DevOps**, and **Full-Stack Development** into one impactful solution.

It bridges **Human Resources (HR)** and **Corporate Social Responsibility (CSR/RSE)**, helping organizations centralize HR processes while promoting **employee engagement** and **sustainability initiatives** — all through a single, intuitive platform.

This project let us go beyond theory and experience the **complete lifecycle of a cloud-native application**, from infrastructure to deployment.

---

## 🚀 Key Highlights

### ☁️ Private Cloud Infrastructure
We built and managed our own cloud environment using **OpenStack**, configuring core services and automating infrastructure deployment from the ground up.

### 💼 The Interhact Platform
Built with **Spring Boot** (backend), **Angular** (frontend), and **MongoDB** (database), Interhact centralizes HR processes while promoting engagement and sustainability through one unified experience.

### 🔧 DevOps & Deployment
Using **Docker**, **Kubernetes**, and **Argo CD**, we containerized, deployed, and managed the application through modern **GitOps** practices.
